README.md of our repo

This is the full layout of the repo behind these slides. CLAUDE.md holds the rules every Claude Code session reads first: allowed layouts, word limits, exact numbers with sources, orange only for CollabLLM. .claude/commands holds our four skills, /ingest, /draft, /revise and /review. /ingest fills sources/notes with notes on the paper, the code and the website, plus a glossary, and puts the original figures in assets/figures. outline.md is the plan: who owns which file and the single message of each slide. Each of us writes only in our own file in sections/, using the layouts in template/. build.py stitches the sections in filename order into one reveal.js deck and screenshots each slide, so we can check for overflow before reviewing.

.claude/commands/ingest.md (first line of each step)

Here is one skill in full. A skill is just a Markdown file of instructions in .claude/commands; typing /ingest with the paper, repo and website links runs it. The description line is what Claude Code shows in the command menu. Steps one and two download the PDF and the LaTeX source and copy the original figure files, so we never redraw a paper figure. Step three is the important one: it writes sources/notes/paper.md with every results table copied in full and a page or section for every claim. Every later step reads facts only from these notes, which keeps the numbers on our slides faithful to the paper. Steps four to seven cover the repo, the website, its look and a glossary. Step eight proposes a slide plan in outline.md, which we then edited and split between the three of us. The skill never writes slides itself.
